# 课堂热词

监听教室麦克风，离线识别同学说的话，分词后统计高频词，显示在屏幕顶部的半透明悬浮条上。托盘常驻后台，带本地 Web 管理页。

## 使用

1. 从 Releases 下载 `ClassroomWords-win64.zip`，解压到任意文件夹（不要放在临时目录）。
2. 运行 `ClassroomWords.exe`，右下角托盘出现麦克风图标。
3. 双击托盘图标打开管理页，在「语音模型」里下载中文小模型（42MB），装好后自动开始监听。

- 显示/隐藏悬浮条：`Ctrl+Alt+H`（可在管理页修改）
- 管理页地址：`http://127.0.0.1:18765`，只有本机可以访问
- 识别完全离线，声音不会上传
- 数据保存在程序目录下的 `data\`（`config.json` 是设置，`records.db` 是课堂记录）

## 功能

- **悬浮条**：显示近 N 分钟的热词，前三名高亮。可以拖动、调透明度、大小、字体、颜色，也可以开鼠标穿透
- **课堂记录**：按节课管理，有热词排行和词频时间轴，可以搜索、删除句子，也可以导出 CSV
- **词库**：自定义词（学科术语、人名）、停用词，以及分词测试
- **设置**：麦克风、统计范围、最少出现次数、热键、开机自启

## 从源码运行

```bat
py -3.12 -m pip install -r requirements.txt
启动.bat
```

打包：`py -3.12 -m pip install pyinstaller`，然后运行 `build.bat`。

技术栈：Python 3.12 · Vosk (Kaldi) · jieba · tkinter · pystray · SQLite
